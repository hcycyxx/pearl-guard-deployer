Pearl 守护器 V2.2.0

适用系统
  Windows 10 / Windows 11 64 位，AMD 或 NVIDIA 独立显卡。
  安装包已包含守护器和 SRBMiner 3.8.0，不要求安装 Python。

一键安装
  1. 双击 Pearl守护器_V2.2.0_一键部署.exe。
  2. 核对安装位置；推荐保留默认目录。
  3. 安装器自动检测显卡型号，并填入矿工名。
  4. 安装完成后，桌面和开始菜单会创建「Pearl 守护器」快捷方式。

首次运行
  守护器会按配置自动开始挖矿，同时显示算力和温度。
  风扇、功耗、核心偏移和显存偏移默认不设置。
  如目标电脑不支持 SRBMiner 启动，界面会保留运行日志，可在此处点「设置」检查矿工路径和显卡参数。

配置与升级
  supervisor.json 位于安装目录。
  覆盖安装不会替换已有的 supervisor.json，用户设置会保留。
  历史日志位于 miner\logs，卸载时默认保留，避免误删数据。

重要说明
  矿工与安装器当前没有商业代码签名证书，Windows 可能显示安全提示。
  SRBMiner 随包分发，请遵守其许可和矿池使用规则。
  不同显卡的风扇、功耗与超频能力不同，程序默认不下发这些参数。
  若 Windows 驱动未识别 AMD/NVIDIA 显卡，安装器会保留检测到的电脑型号作为矿工名，并提示手动核对。
